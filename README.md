# Valiant Networks

Valiant Networks, Inc. was a dot-com-era network testing, design, and consulting firm serving carriers and network equipment vendors. It raised a $21M Series B in October 1999 and cut staff (including its CEO) in the 2001 telecom downturn. Surfaced as a portfolio company of battery-ventures (Battery Ventures list of all companies). The company is defunct with no surviving web presence or API surface.
